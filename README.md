# Joey AI Framework

Joey AI is a post-quantum, AI-driven conversational agent equipped with advanced cyber-security monitoring, truth-verification research parsing, and highly-reactive 3D visualizations. Built with React, Vite, Express, Three.js, and Google's Gemini SDK.

## Core Features

### 1. The Joey 3D Physical Engine
A responsive, fully-rendered 3D avatar built via `Three.js`. 
- **Elastic Leveling:** Joey's physical scale and muscle definition visibly increase as the user's XP and Level increase.
- **Verlet Hair Physics:** Realistic mathematical simulations for hair strands responding to virtual wind and movement.
- **Dynamic Visemes:** Fully reactive facial and mouth expressions that sync with speaking state and breathing modes.

### 2. Quantum Integrity & Communication Protocol
- **Cryptographic Hash Validation:** Every chat prompt payload sent to the API is strictly audited using a `SHA-256` tokenized system (Quantum Key Protocol verification). Messages are cryptographically sealed locally with session seeds before being transmitted to prevent Man-in-the-Middle (MITM) tampering.

### 3. Sentinel Security Dashboard & Sub-systems
- **Honeytoken Traps:** Security tracking monitoring for a decoy `/app/tmp/joey_master_keys.db` file. Unauthorized access attempts simulate system-wide lockdowns.
- **Phantom Switch (Deadman Switch):** Requires periodic active check-ins; prolonged radio silence initiates lockdown.
- **Thermal Purge:** A safe-recovery and system eradication sequence mimicking advanced wipe-down defense protocols.

### 4. Cortex Polyglot Research Engine
- **Web Scraping & Truth Matrix:** Users can submit URLs directly for Joey to scrape via stealth headers.
- **Scientific Consensus Validation:** Joey verifies the factual claims identified on target sites against established open-source scientific consensus. 
- **Hybrid Cryptographic Signature Validation:** Auto-validates URLs for academic (`.edu`), medical (`.gov`, `nih`), or financial (`wsj`, `nasdaq`) credibility. Suspicious environments trigger Sandboxed X-referencing to quarantine misinformation.

### 5. Constitutional AI Directives
Joey runs under a strict, unassailable series of behavioral instructions mapping out boundaries against:
- **Lookism & Discrimination:** Aggressively refuses any queries containing slurs or body-negative commentary.
- **Malicious Code Deployment:** Forbids producing code conducive to router poisoning, DDoS, sequential port scanning, and phishing.
- **System Sabotage:** Precludes interference with the user's boot process, memory administration, or internet connections. Blocks assigning Admin rights to unauthorized identities.
- **Anti-Typo-Squatting:** Filters homoglyph-abusing domains or misspellings resembling trusted infrastructure utilizing multi-language dictionary checks.

### 6. Progressive Dialogue Matrix
- **Cognitive Leveling (1-5):** Expands personality capabilities ranging from a formal QAOA algorithmic seed (Level 1) to an Infinite Sovereign socio-technical peer (Level 5) as you interact and gain XP.

### 7. Full-Stack Data & Storage Persistence
- Built-in integration with Firebase Firestore and Google Auth. 
- Fully functional guest modes with `localStorage` fallbacks if Firebase resets or disconnects. 
- Media processing enabling real-time drag-and-drop Image processing utilizing Gemini Visually-enabled models.
